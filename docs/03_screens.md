# My Trip — 画面設計書

Web / iOS 共通の画面構成。ビジュアルは「旅ノート」トーン(温かみのある紙+インク色、地図が主役)。

## 画面一覧

| ID | 画面 | 役割 |
|----|------|------|
| S-01 | ホーム | 「旅開始」の大ボタン+直近の旅サマリー |
| S-02 | 記録中 | ライブ統計(経過時間・距離・スポット数)+現在地ミニマップ+「旅終了」 |
| S-03 | 旅一覧 | 過去の旅のカードリスト |
| S-04 | 旅詳細 | 地図(軌跡+ピン)+統計+タイムライン。タイトル/メモ/スポット編集 |
| S-05 | 設定 | 逆ジオコーディングON/OFF、エクスポート/インポート、データ全削除 |
| S-06 | 計画一覧 | 計画のカードリスト(期間中/これから/過去)+新規作成 |
| S-07 | 計画詳細 | タイトル・期間・メモの編集+行きたい場所リスト+「この計画で旅をはじめる」 |

## S-01 ホーム

```
┌──────────────────────────┐
│ My Trip            [設定] │
│                          │
│      ○ 旅をはじめる       │   ← 主ボタン(位置許可を要求)
│                          │
│ 最近の旅                  │
│ ┌──────────────────────┐ │
│ │ 6/21 鎌倉の旅          │ │
│ │ 8スポット・12.3km・6h   │ │
│ └──────────────────────┘ │
│ [すべての旅を見る →]       │
└──────────────────────────┘
```

- 位置情報の許可が拒否された場合は理由と再許可手順を表示
- 記録中の旅が残っている場合は「旅を再開する」に切り替わる(F-06)
- 「最近の旅」の上に「旅の計画」セクションを置く(P-03): 進行中・これからの計画を最大2件表示し、計画一覧(S-06)へのリンクを常設。計画がなければ誘導文+「計画をたてる」リンク

## S-06 計画一覧 / S-07 計画詳細

```
┌──────────────────────────┐   ┌──────────────────────────┐
│ ← 旅の計画                │   │ ← 鎌倉の旅 計画      [編集]│
│ [新しい計画をつくる]       │   │ 7/20(月)〜7/21(火)        │
│                          │   │                          │
│ 旅の期間中                │   │ 行きたい場所               │
│ ┌ 鎌倉の旅 [記録済み] ───┐ │   │ 1. 鶴岡八幡宮  [↑][↓]     │
│ │ 7/20(月)〜7/21(火)     │ │   │ 2. 小町通り    [↑][↓]     │
│ └──────────────────────┘ │   │ [+ 場所を追加]            │
│ これからの旅              │   │                          │
│ 過去の計画                │   │ [この計画で旅をはじめる]    │
└──────────────────────────┘   │ [この計画を削除する]       │
                               └──────────────────────────┘
```

- 一覧は「期間中 → これから(開始日が近い順) → 過去(新しい順)」で区分表示(S-06)
- 計画詳細(S-07)ではタイトル・開始日/終了日・メモを編集。終了日は開始日より前にできない
- 行きたい場所は名前+メモを編集でき、並べ替え(Web: ↑↓ボタン / iOS: 編集モードのドラッグ)できる
- 「この計画で旅をはじめる」は計画タイトルを引き継いで記録を開始し、計画に旅を紐づける(P-04)。記録中は開始ボタンの代わりに案内文を表示
- 記録済みの計画はバッジ「記録済み」を表示し、旅詳細(S-04)へのリンクカードを置く

## S-02 記録中

```
┌──────────────────────────┐
│ ● 記録中  02:34:12        │   ← 赤ドットは点滅させない(視覚的うるささ回避、opacityで穏やかに)
│ ┌──────────────────────┐ │
│ │  ミニマップ(現在地+軌跡)│ │
│ └──────────────────────┘ │
│  12.3 km   5 スポット     │   ← 統計タイル
│                          │
│ 直近のスポット             │
│  ・鶴岡八幡宮 (14:02〜)    │
│                          │
│ [■ 旅を終了する]          │   ← 確認ダイアログを挟む
└──────────────────────────┘
```

- Web: タブを閉じると記録が止まる旨を控えめに常設表示
- スポット検出時はリストに追記(トースト等の割り込みはしない)
- (iOS) 「メモ・写真」セクションから記録中でも旅メモの編集・写真の添付ができる(F-11)

## S-04 旅詳細

```
┌──────────────────────────┐
│ ← 6/21 鎌倉の旅      [編集]│
│ ┌──────────────────────┐ │
│ │   地図: 軌跡ポリライン    │ │
│ │   + 番号付きスポットピン  │ │
│ └──────────────────────┘ │
│ 12.3km・6h02m・8スポット・9,432歩(iOS) │
│                          │
│ タイムライン               │
│ ◉ 09:12 鎌倉駅 (24分)     │
│ ┆ 徒歩 1.2km・18分        │
│ ◉ 09:54 鶴岡八幡宮 (41分)  │
│ ┆ …                     │
│ ◉ 15:03 長谷寺 (52分)     │
└──────────────────────────┘
```

- タイムラインのスポットをタップ → 地図が該当ピンへ移動
- スポット行の編集で名前・メモ変更、削除
- 移動セグメントはスポット間の軌跡から距離・時間を導出表示
- (iOS) 写真セクション: フォトライブラリから写真を添付(正方形グリッド、タップで拡大、長押し/ビューアで削除)。写真は端末内保存のみ
- (iOS) ツールバーからアーカイブ/アーカイブ解除(S-03のセグメント「アーカイブ」に移動)

## デザイントークン(Web)

| トークン | ライト | ダーク |
|---|---|---|
| 背景 `--bg` | `#faf7f2`(生成り) | `#171512` |
| 面 `--surface` | `#ffffff` | `#211e1a` |
| インク `--ink` | `#2b2620` | `#ece7df` |
| 補助 `--muted` | `#7a715f` | `#a49a88` |
| アクセント `--accent` | `#c2571b`(朱) | `#e07a3f` |
| 記録中 `--rec` | `#b3261e` | `#ff6b5e` |
| 線 `--line` | `#e8e1d4` | `#37322b` |

- フォント: システムフォントスタック(ヒラギノ/Noto Sans JP フォールバック)。数値統計は `font-variant-numeric: tabular-nums`
- 角丸: カード 12px / ボタン 999px(ピル)
- 8pxグリッド。タップターゲット44px以上
- コントラストはWCAG AA以上を確認済みの組み合わせのみ使用

## アクセシビリティ要件

- 全操作をキーボードのみで完結可能(Web)
- 記録状態の変化は `aria-live="polite"` で通知
- 地図はキーボード非依存の補完としてタイムライン(テキスト)が常に併存
- 色のみに依存しない(記録中は●+「記録中」テキスト)
